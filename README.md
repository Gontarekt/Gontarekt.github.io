# Gontarekt.github.io

To publish changes:
- In terminal enter: 'npm run build'
- Copy the index.html and assets folder inside the dist folder to the root of the repo
- Commit and Push changes

To Edit:
- In terminal enter: 'npm run dev'
- Open the Localhost ip in browser to see changes
- Navigate to the src folder and edit the .tsx, and .css files.
